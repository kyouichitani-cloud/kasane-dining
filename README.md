# KASANE DINING

UI/UX Pro Maxを起点に設計した、架空の季節料理レストランのWebサイトです。PC・iPad・スマートフォンで同じ画面を縮小するのではなく、情報量、導線、画像比率、ナビゲーションを端末ごとに組み替えています。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

## レスポンシブ設計

- PC（1100px以上）: 横長のファーストビュー、中央ナビ、左右非対称の編集レイアウト、追従する料理写真
- iPad（768〜1099px）: 2カラムを軸に、予約ボタンとハンバーガーメニューを併用
- スマートフォン（767px以下）: 1カラム、短い移動距離、大きなタップ領域、アニメーションを抑えた構成

## 主な機能

- 季節のコース、空間、アクセス情報
- 日付に連動する予約時間（平日・日曜・定休日を判定）
- 入力エラーの項目別表示と先頭エラーへのフォーカス
- 予約内容の下書き保存
- 入力内容を失わずに確認できるプライバシーポリシーのモーダル
- キーボード操作、フォーカス表示、動きを減らす設定への対応
- OGP、構造化データ、検索向けメタデータ
